1. INTRODUCTION

Netflix Clone (Streamly) is a full-stack, enterprise-grade on-demand video streaming web platform engineered to deliver the seamless, responsive user experience of world-class video entertainment systems. The application combines an ultra-modern, reactive frontend constructed with React 19, TypeScript, and Tailwind CSS with a robust, scalable backend powered by Node.js, Express.js, and MongoDB.

Users can register, sign in via token-based authentication, configure personalized multi-profile accounts (including Kids Safe Mode), browse dynamically categorized movies and TV series, stream high-definition video content with a custom interactive player, maintain a personal watchlist ("My List"), track watch timestamps across sessions, upgrade subscriptions via Stripe, and access an administrative management console.

2. OBJECTIVES & PROBLEM STATEMENT

Objectives

  • Develop a high-performance, responsive online video streaming platform mimicking Netflix's UI/UX.
  • Implement secure token-based user authentication (JWT) and salted password hashing (bcryptjs).
  • Provide a multi-profile environment supporting up to 5 profiles per account with avatar customization and Kids Mode.
  • Deliver rich media discovery via auto-playing Hero banners, categorized sliding rows, and real-time search.
  • Engineer a custom video player supporting playback speed, audio/subtitle toggles, and resume-from-last-watched.
  • Integrate Stripe payment processing for automated subscription plan billing and checkout.
  • Provide an administrative portal with real-time KPIs, user management, and content catalog editing.
  • Demonstrate full-stack software development best practices and robust cloud data modeling.

Problem Statement

Traditional online media portals frequently suffer from rigid user interfaces, lack of multi-profile personalization, vulnerable authentication workflows, poor responsive scaling, and complex subscription billing. Netflix Clone (Streamly) automates account security, multi-profile state isolation, catalog indexing, video playback synchronization, and payment processing within a single unified web platform.

5. SYSTEM ARCHITECTURE & WORKFLOW

Streamly follows a 3-Tier Client-Server Architecture. The React 19 Single Page Application communicates with the Express.js backend via asynchronous REST API requests, while MongoDB provides persistent document storage. Protected routes are secured using JWT tokens passed via HTTP-only cookies.

Workflow: User → Registration/Login → JWT Authentication → Profile Selection → Browse Catalog → Media Details Modal → Custom Video Player → Watch Progress Sync → My List → Stripe Subscription → Admin Portal

The user accesses the application, triggers the animated startup splash, and logs in or registers. After authentication, the user selects a viewer profile. The homepage fetches categorized browse content with auto-playing Hero trailers. Selecting a title opens the detail modal or launches the custom video player, which continuously synchronizes watch timestamps with MongoDB. Users can manage their subscription through Stripe, while administrators access the admin portal to monitor analytics and modify catalogs.

6. MODULE DESCRIPTION

Registration & Authentication Module

Handles user sign-up, credential validation, salted password hashing via bcrypt (10 rounds), and JWT token issuance stored in secure HTTP-only cookies with rate-limiting protection.

Multi-Profile Management Module

Supports up to 5 user profiles per account with independent avatars, PIN code security, Kids Mode content filtering, individual watchlists ("My List"), and playback histories.

Browse & Hero Banner Module

Aggregates categorized media rows (Trending, Top 10, Action, Drama, Sci-Fi) and renders an auto-playing Hero featured banner with background trailer playback and audio toggles.

Custom Video Streaming & Player Module

Features an HTML5 video player with time scrubber, volume sliders, 10-second skip/rewind, speed modifier (0.5x to 2x), subtitle/audio selectors, and auto-next episode triggers.

Watchlist ("My List") & History Tracking Module

Maintains persistent media bookmarks per profile in MongoDB and records playback timestamps for seamless "Resume Watching" across sessions.

Admin Management & Analytics Module

Provides role-protected endpoints for platform KPIs (active users, MRR, catalog size), user account CRUD, media catalog creation/editing, and plan pricing controls.

7. FRONTEND IMPLEMENTATION

The frontend is developed using React 19, TypeScript, and Tailwind CSS. Dynamic routing is handled by React Router DOM v7 with lazy loading (`React.lazy` and `Suspense`). Centralized state is synchronized using React Context (`AppProvider`), while Motion (Framer Motion) powers the signature letter-unfolding splash screen, modal overlays, and hover expansion cards.

8. BACKEND, DATABASE & AUTHENTICATION

The backend is engineered with Node.js and Express.js in ES Module format. MongoDB with Mongoose ODM stores normalized collections for `User`, `Profile`, `Media`, `Plan`, and `Notification`.

Auth Flow: Registration → Salted Password Hashing → MongoDB Storage → Login → Credential Check → JWT Issuance → HTTP-only Cookie → Authenticated API Requests

9. MEDIA STREAMING, CATALOG & SUBSCRIPTION INTEGRATION

The system indexes rich media metadata with high-speed caching and TMDB fallback integration. Video streams synchronize playback timestamps to MongoDB every 5 seconds. Secure subscription payments and upgrades are handled end-to-end using Stripe API and `@stripe/react-stripe-js`.

10. TESTING & CHALLENGES

Testing

  • Authentication & Security: Registration, login, token issuance, password hashing, and route guards verified using Postman and Jest.
  • Multi-Profile Isolation: Verified independent watchlists, watch progress, and Kids Mode filters between profiles.
  • Media Browsing & Video Player: Tested infinite carousel sliding, debounced search, modal previews, video scrubber, playback speeds, and fullscreen mode across multiple modern browsers.
  • Stripe Payment Integration: Tested end-to-end checkout with Stripe test tokens and validated automatic subscription tier upgrades.
  • API Integration & Stress: Verified REST API responses using Supertest and validated concurrent server load stability using Autocannon.

Challenges Faced

  • Playback Synchronization: Synchronizing video timestamps in real time was solved using 5-second debounced client-side heartbeats.
  • Hover Card Expansion: Preventing carousel clipping on hover was resolved using Framer Motion and elevated CSS portal z-index layers.
  • Security & ReDoS Mitigation: Protected search queries against Regular Expression Denial of Service by escaping inputs before database query compilation.
  • Admin Access Control: Guaranteed security using server-side `adminOnly` middleware verifying JWT claims against MongoDB records.
